## Этап 9 — Донат (ЮKassa через Telegram Payments)

**Важно (проверено 2026-08-05, см. CLAUDE.md "Донат"):** по правилам Telegram цифровые
товары обязаны продаваться за Telegram Stars, ЮKassa официально — только для физических
товаров. Пользователь осознанно решил всё равно принимать рубли через ЮKassa для коинов —
это его решение, реализуем как запрошено, без Stars.

Схема — НЕ прямой REST API ЮKassa, а стандартный Telegram Bot Payments: ЮKassa подключается
разово через BotFather (Bot Settings -> Payments -> ЮKassa), это даёт `provider_token`
(`YOOKASSA_PROVIDER_TOKEN` в `.env`). Дальше вся оплата — обычные апдейты Telegram, отдельный
вебхук от ЮKassa не нужен:

**2026-08-05 — реализовано.**

- [x] Экран `/donate` (кнопка "💎 Донат" на главном меню, была без хендлера): баланс коинов + пресеты суммы (50/100/300/500/1000/3000 ₽) + "Своя сумма" (FSM, 50-50000 ₽)
- [x] `sendInvoice(provider_token=..., currency="RUB", prices=[LabeledPrice(amount=рубли×100)])` — суммы в копейках, 1₽ = 1 коин (`config/game: DONATE_COINS_PER_RUB`)
- [x] Хендлер `pre_checkout_query` — отвечает `ok=True` сразу, без похода в БД (важен SLA 10 секунд; проверка "товар в наличии" не нужна — коины не ограниченный ресурс, а инвойс создаём только сами, сумма в нём валидна по построению)
- [x] Хендлер `successful_payment` (`F.successful_payment` на `Message`) — зачисление коинов через `services/donate.credit_payment`, запись в `payments` (сразу со статусом `succeeded`) и `transactions`. Идемпотентность — атомарный `INSERT ... ON CONFLICT DO NOTHING` по `telegram_payment_charge_id` (уникальный constraint), не Redis-лок: источник повторов тут — сервер Telegram (может передоставить апдейт), а не повторный клик игрока в UI
- [x] **Важный фикс существующих middleware**: `BanCheckMiddleware`/`TechModeMiddleware` теперь пропускают `Message` с `successful_payment` без блокировки, даже если игрок забанен или включён техрежим — деньги Telegram уже списал ДО того, как этот апдейт дошёл до бота, блокировка апдейта означала бы забрать деньги и не начислить коины без возврата
- [x] Если `YOOKASSA_PROVIDER_TOKEN` не задан (пустая строка в `.env`, дефолт в `Settings`) — экран доната отвечает "временно недоступен" вместо падения на вызове `sendInvoice` с невалидным `provider_token`

- [x] Массовые действия (выдать всем коины/тикеты/пыль): **не Python-цикл по 30k строк** — один `UPDATE` на всех игроков + `INSERT ... SELECT` в `transactions` из того же набора обновлённых строк (writable CTE), одним SQL-выражением на каждое действие (см. правило 3)
